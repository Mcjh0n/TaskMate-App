# Category and filter feedback questionnaire

TaskMate currently has **no recommendation or ranking algorithm**. This template evaluates the usefulness of categories and filters only. Participant count, sampling, acceptance thresholds, and schedule are **TBD (not finalized)**. No responses or results are included.

1. Which categories were easiest to understand? [free text]
2. Which category labels were unclear or missing? [free text]
3. Were category, work mode, budget, and keyword filters useful? [1–5 each]
4. Which filters did you expect but could not find? [free text]
5. Did the filtered listings match the tasks you were looking for? [1–5]
6. What would make task suitability easier to judge from the listing? [free text]
